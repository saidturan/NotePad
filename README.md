Bu proje, C# kullanılarak hazırlanmış basit ama işlevsel bir **Not Defteri** uygulamasıdır.
**Özellikler**
	1.	Yeni / Aç / Kaydet / Farklı Kaydet
	2.	Kes / Kopyala / Yapıştır / Geri Al
	3.  Tümünü Seç
 	4.	Satır kaydırma 
	5.	Yazı tipi seçme
	6.	Durum çubuğu
	7.	Basit “Bul” özelliği
	8.	Kaydedilmemiş değişiklik uyarısı
	9.	UTF-8 metin desteği
